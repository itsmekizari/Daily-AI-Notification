# GitHub Build

1. Replace the repository `android/` folder with the `android/` folder from this package.
2. Replace `.github/workflows/android.yml` with the version from this package.
3. Keep `backend/`, `docs/`, and `README.md`.
4. Keep the OpenAI API key only in Render Environment Variables.
5. Run the `Build Android APK` workflow.
6. Download the `Daily-AI-Notification-debug-apk-v1.4` artifact.
