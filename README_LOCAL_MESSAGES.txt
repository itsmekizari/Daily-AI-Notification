Daily AI Notification - Local Notification Message Bank

This version includes 10,000 built-in notification messages split across 10 Java files:
LocalMessageBankPart01.java ... LocalMessageBankPart10.java

LocalMessageBank.java is the single formatter/entry point used by DailyMessageReceiver.
No OpenAI request is needed to generate the daily notification.

Messages are shuffled locally and selected without repetition until the current pool is exhausted.
The Test Notification button remains available in the main screen.
