# Android / Sketchware side

The Java files in this directory are the source reference for the Sketchware Pro project.

Package:
`com.kizari.dailynotify`

Main components:
- `MainActivity.java`
- `ApiClient.java`
- `DailyMessageReceiver.java`
- `BootReceiver.java`
- `NotificationHelper.java`
- `FallbackMessages.java`

For Sketchware Pro, add the classes through the appropriate Java/source-code section and configure the manifest permissions/receivers.
